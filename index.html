HOW IT WORKS

고르고, 만들고, 다시 엽니다.

Home과 Studio에서 팩을 찾고, Compose에서 한 장을 만든 뒤, Pages에서 다시 꺼내 봅니다.

01 / 고르기

스티커팩과 종이를 먼저 고릅니다.

Home과 Studio에서 현재 팩을 보고, 팩 상세에서 구성과 샘플을 확인한 뒤 만들기로 넘어갑니다.

  • Home · Studio
  • 팩 상세
  • 샘플 확인
02 / 만들기

사진, 종이, 스티커, 글을 한 장에 놓습니다.

빈 페이지나 사진에서 시작합니다. 요소를 선택해 이동하고, 복제하고, 순서를 바꾸며 작업 내용은 기기에 자동 저장됩니다.

  • 사진 · 종이 · 스티커 · 텍스트
  • undo · redo
  • 자동 저장
03 / 다시 열기

만든 페이지를 날짜와 검색으로 다시 찾습니다.

저장한 페이지를 열어 다시 편집하고, 필요한 결과물은 PNG로 저장하거나 시스템 공유 기능으로 보냅니다.

  • 날짜 탐색 · 검색
  • 재편집
  • 이미지 저장 · 공유
STUDIO 01 / 03

SCREEN MAP

현재 화면을 전부 펼쳐 봅니다.

아래 이미지는 현재 개발 빌드의 실제 화면입니다. 홈의 다른 상태와 팩 상세, 달력처럼 주 화면에서 이어지는 화면도 함께 넣었습니다.

HOME

오늘의 페이지, 추천 팩, 최근 작업.

앱을 열면 오늘 만들기와 현재 팩을 먼저 보여줍니다.

HOME / PACK HIGHLIGHT

홈에서 팩을 바꿔 보는 상태.

팩 배너와 추천 내용이 바뀐 홈 화면입니다.

STUDIO

스티커팩을 둘러봅니다.

현재 카탈로그의 팩을 모아 보고 상세로 들어갑니다.

PACK DETAIL

팩 구성과 샘플을 확인하고 바로 사용합니다.

팩 설명, 포함 소재, 샘플 페이지를 보고 만들기로 이어집니다.

CREATE

시작 방식을 고릅니다.

빈 페이지, 사진, 저장한 템플릿, 이전 작업에서 시작합니다.

COMPOSE

한 장의 페이지를 편집합니다.

레이어를 선택하고 이동·복제·정렬하며 작업합니다.

PAGES

저장한 페이지를 다시 찾습니다.

날짜와 검색으로 페이지를 찾고, 다시 열어 편집하거나 여러 장을 선택해 공유합니다.

CALENDAR

월 단위로 날짜를 이동합니다.

Pages의 날짜 스트립에서 월간 달력을 열어 원하는 시점으로 이동합니다.

LIBRARY

저장한 재료를 모아 봅니다.

사용자 템플릿, 북마크, 내 팩을 한곳에서 확인합니다.

CURRENT PACKS

실제 아델리드로우 자산을 씁니다.

현재 빌드에는 Home Sweet Home, Spring Fox Renewal, Lemon Pound Cake와 기본 흰 모조지가 들어 있습니다. 출시 팩 목록은 아직 확정 전입니다.

COMPOSE

편집할 때는 페이지가 중심에 있습니다.

사진, 종이, 스티커, 텍스트를 한 캔버스에 놓습니다. 선택한 요소의 도구만 표시하고, 작업은 자동 저장합니다.
